# E-commerce Project

Проект электронной коммерции с базовой структурой классов для управления продуктами и категориями.

## Описание

Проект предоставляет объектно-ориентированную модель для интернет-магазина с возможностью:
- Создания и управления продуктами
- Группировки продуктов по категориям
- Итерации по продуктам в категории
- Поддержки различных типов товаров (смартфоны, газонная трава)

## Структура классов

### Product (Базовый класс товара)
- Атрибуты: название, описание, цена (приватная), количество
- Магические методы: `__str__`, `__add__`, `__radd__`
- Свойства: price (getter/setter с валидацией)
- Класс-метод: `new_product()` - создание или обновление продукта

### Category (Категория товаров)
- Атрибуты: название, описание, список продуктов (приватный)
- Подсчет количества категорий и продуктов (класс-атрибуты)
- Методы: добавление продукта, получение списка продуктов
- Класс-метод: `add_categories()` - создание категорий из JSON-данных

### CategoryIterator (Итератор)
- Итератор для последовательного перебора продуктов в категории

### Специализированные классы
- **Smartphone** (подкласс Product): эффективность, модель, память, цвет
- **LawnGrass** (подкласс Product): страна, период всхожести, цвет

## Утилиты (utils.py)

- `get_from_json(path: str) -> list`: загрузка данных из JSON-файла

Покрытие тестами: 95%

## Особенности реализации

- Приватные атрибуты для цены (Product) и списка продуктов (Category)
- Валидация при установке цены (с подтверждением при понижении)
- Специальная обработка для `sum()` через магические методы
- Type hints для всех методов
- Обработка исключений при несоответствии типов
