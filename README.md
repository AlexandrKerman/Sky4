# E-commerce Project

Проект электронной коммерции с объектно-ориентированной моделью для управления продуктами и категориями.

## Описание

Проект предоставляет расширенную объектно-ориентированную модель для интернет-магазина с использованием абстрактных классов, миксинов и итераторов.

## Структура классов

### Абстрактные классы

#### BaseProduct (ABC)
- Абстрактный базовый класс для всех продуктов
- Обязательные методы для реализации:
  - `new_product()` - создание или обновление продукта
  - `price()` - геттер для цены

### Миксины

#### PrintMixin
- Выводит `repr()` объекта при инициализации
- Полезен для отладки и отслеживания создания объектов

### Основные классы

#### Product (BaseProduct, PrintMixin)
- Атрибуты: название, описание, цена (приватная), количество
- Магические методы: `__str__`, `__repr__`, `__add__`, `__radd__`
- Свойства: price (getter/setter с валидацией)
- Класс-метод: `new_product()` - создание или обновление продукта

#### Category
- Атрибуты: название, описание, список продуктов (приватный)
- Подсчет количества категорий и продуктов (класс-атрибуты)
- Методы: добавление продукта, получение списка продуктов
- Класс-метод: `add_categories()` - создание категорий из JSON-данных

#### CategoryIterator
- Итератор для последовательного перебора продуктов в категории

### Специализированные классы (наследуются от Product)
- **Smartphone**: эффективность, модель, память, цвет
- **LawnGrass**: страна, период всхожести, цвет

## Утилиты (utils.py)

- `get_from_json(path: str) -> list`: загрузка данных из JSON-файла

## Особенности реализации

- **Абстрактный базовый класс** `BaseProduct` для обеспечения единого интерфейса
- **PrintMixin** для автоматического вывода информации при создании объектов
- Приватные атрибуты для цены (Product) и списка продуктов (Category)
- Валидация при установке цены (с подтверждением при понижении)
- Специальная обработка для `sum()` через магические методы
- Полная типизация (type hints) для всех методов
- Обработка исключений при несоответствии типов

## Пример использования

```python
# Создание продукта
product = Product("Телефон", "Смартфон", 50000, 10)

# Создание категории с продуктами
category = Category("Электроника", "Электронные товары", [product])

# Итерация по продуктам
for product in CategoryIterator(category):
    print(product)
